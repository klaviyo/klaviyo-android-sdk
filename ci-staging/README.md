# Staged CI changes (MAGE-1727)

This directory holds the `.github/` changes that make klaviyo-android-sdk call the shared SDK CI in klaviyo-react-native-sdk (branch `ecm/mage-1726/shared-ci`, to be flipped to `@master` once klaviyo-react-native-sdk#501 merges), staged here because the push token can't write workflow files. Copy each file under `ci-staging/github/` to the same path under `.github/` (they are complete files, not diffs) and delete every path listed in `ci-staging/DELETE`, then remove `ci-staging/`. The result drops this repo's own `notify-slack` action, its `promotion-check.sh` and the sparse "Checkout Slack action" steps; every Slack step uses the shared `notify-slack`; `pr-target-check.yml`, `stale.yml` and `promotion-check.yml` become stubs over the shared actions (with this repo's `bump-version.sh` files as `bump-files`); `jitpack.yml` syncs Linear through `linear-release-sync`; `publish-release.yml`'s `prepare` job calls `release-preflight.yml` with the strings.xml check as `sdk-checks` while its `publish` and `stopped` jobs stay here; and `rel-branch.yml` keeps its triggers and calls `rel-branch-core.yml` with `./bump-version.sh` and the React Native and Flutter dispatch targets.
