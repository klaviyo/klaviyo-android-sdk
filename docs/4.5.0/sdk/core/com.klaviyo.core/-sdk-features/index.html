SdkFeatures

object SdkFeatures

Serializes SDK feature-adoption flags into the X-Klaviyo-Sdk-Features header, used for SDK adoption telemetry.

Each flag is sourced from a manifest <meta-data> boolean and reported only when the host actually declared that key, so the backend can distinguish "configured false" from "not configured" (absent keys are omitted from the header).
