BoundedIdSet

class BoundedIdSet(capacity: Int = DEFAULT_CAPACITY)

Thread-safe, fixed-capacity set of string IDs with FIFO eviction, used as an in-memory dedup guard for recently-seen identifiers.

When the set is full, inserting a new ID evicts the oldest-inserted one. A duplicate insert is a no-op that does not refresh the ID's position in eviction order, so the set behaves as a sliding window over the most recently first-seen IDs.

All operations are guarded by an intrinsic lock, so the set is safe to share across threads.

Parameters

capacity

maximum number of IDs retained before the oldest is evicted.
