Subscription

class Subscription

Represents a request to subscribe the current profile to a Klaviyo list, with optional per-channel marketing/transactional consent.

Consent is expressed through channels. A null channels value grants the server's default of MARKETING consent on every channel the profile has an identifier for, and is only reachable through allAvailableMarketing — the public constructor requires channels so a broad grant is never the result of an omitted argument.
